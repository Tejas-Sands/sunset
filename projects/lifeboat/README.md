# LIFEBOAT

**Status: main candidate, retained by the user on 22 October 2026.** The final build choice remains open as the search continues for more unusual mechanisms.

LIFEBOAT would let the owner of a paid agent service replace its operator while retaining its identity, work records and monetary state, and refusing new financial actions from the replaced operator.
