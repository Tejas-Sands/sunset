# COMMONS

**Status: one of the main project candidates, retained by the user on 22 October 2026.** The final build choice remains open while research continues.

COMMONS would let a community derive useful statistical knowledge from privately contributed information while controlling approved use and service revenue. The first proposed product helps independent workers understand effective earnings after fees, expenses and unpaid time.

- [Full proposal](PROPOSAL.md): user problem, architecture, competitors, demo, development scope, tracks, pilot and risks.
- [Selection and research audit](SELECTION.md): alternatives considered and corrections to the independent research pass.
- [Primary sources](sources.json): references and the limits of what each supports.
- [Project status](status.json): current selection and preparation state.
- [Research updates](RESEARCH_UPDATES.md): later findings that qualify the original proposal.
- [Artifact verification](verification.json): file and link checks, not product validation.

The next decisive technical check is confidential-runtime compatibility and a defensible fixed statistical release. The adoption check is whether an existing worker community wants the resulting benchmark.

This directory holds the maintained candidate documents. The [original research snapshot](../../research/commons-2026-10-22/README.md) remains available for reference. Development is scoped to 1–14 November; no product implementation is claimed.
