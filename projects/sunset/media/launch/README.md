# SUNSET launch film

An 82-second editorial product film with local AI narration, captions, original ambient chords, the existing SUNSET identity, real browser captures and clearly labeled summaries of finalized testnet transactions. It uses no paid rendering service. The refund section describes the contract rule; it does not show a completed live expiry-refund campaign.

From the repository root, using the retained capture/voice delivery:

```sh
python3 projects/sunset/media/launch/render.py
```

Requires Python 3, Pillow, fontTools with WOFF2 support, CairoSVG, FFmpeg and ffprobe. These were already available for this render. `--assets PATH` selects another delivery directory; `--cards-only` renders review stills without encoding a film. The edit uses the exact voice sample timings in `voice/timing.json`, paced to 82 seconds with pitch-preserving `atempo`; captions are scaled by the same factor.

Inputs stay in ignored `.publication/sunset-launch-v1/voice/` and `footage/`. Retain those original files to reproduce this edit; a fresh Git clone does not contain recordings or model weights. `storyboard.json` names the genuine captures and crop regions. No browser or wallet mockup is generated by the renderer. `render.py` creates the branded cards, camera motion, original chord bed and final export using the existing artwork, SVG icon and Geist font.

The public source includes `narration.txt` and exact per-sentence `timing.json`. The raw voice is Kokoro-ONNX 0.6.1, pretrained `af_heart`, speed 0.92, mono 24 kHz, 73.6900417 seconds; the film uses pitch-preserving pacing to 82 seconds. [Official model release](https://github.com/thewh1teagle/kokoro-onnx/releases/tag/model-files-v1.1): FP16 model SHA-256 `f3a290d384fbb27966d462905c71a46cef9e5fd00516b40df32a0b4afe77ac96`, voice-bank SHA-256 `bca610b8308e8d99f32e6fe4197e7ec01679264efed0cac9140fe9c29f1fbf7d`. The model is Apache-2.0 and wrapper MIT; the retained voice delivery includes upstream license texts, model card, download URLs and hashes. No voice cloning was used.

The existing hero artwork retains its [original generation prompt/provenance](../../public/images/README.md); Geist retains its [OFL license](../../public/fonts/OFL-Geist.txt). The SVG SUNSET icon is reused directly. The ambient chord bed is composed procedurally in `render.py`, with no commercial recording or third-party samples. Full final input hashes and credits are output alongside the film. Actual campaign and browser proof are in [testnet-showcase.json](../../evidence/testnet-showcase.json) and [browser-showcase.json](../../evidence/browser-showcase.json).

Outputs are under `.publication/sunset-launch-v1/render/`:

- `sunset-launch.mp4`: 1920 × 1080, 25fps, H.264/AAC, YUV420P, fast-start MP4, burned-in captions and a persistent NEAR TESTNET label.
- `sunset-launch.srt` and `sunset-launch-poster.png`.
- `contact-sheet.jpg`, `ffprobe.json`, `media-provenance.json` and `sunset-launch-credits.md` for review and exact input identities.

The final file is checked for codecs, dimensions, duration and file size. Keyframes and captions are visually inspected. Audio levels and synchronization can be checked objectively, but listening quality needs an actual playback check. This film is an edited presentation of genuine still captures, not a continuous screen recording. Main-campaign settlement is supported by the separate public testnet evidence; no independent-human sponsorship, educator review or mainnet claim is implied.

Do not commit the generated film, raw capture/voice files, model weights, caches or private release inputs. The short renderer, storyboard and this document are the intended source files.
