# SUNSET v12 — research, script and visual concept

This batch follows the requested order: [research actual uses](RESEARCH.md), [propose the main script](SCRIPT_DRAFT.md), then [show the animation style](STYLE.md). It is not another finished launch film. V11's Git-command example and story were rejected; its exact movie and technical checks remain preserved.

The user's central why is now the opening motivation: **valuable work can be free to use while its creator is compensated and can keep creating.** Lessons, workshop kits and useful guides establish the scope. A First Community Workshop Kit is one concrete example rather than the product's whole definition.

The new script separates the creator, sponsors and public readers. Sponsorship compensates the public release of a prepared edition. NEAR supplies conditional custody/creator-credit/refund rules; the browser copy supplies reader access. A downloaded resource requires no terminal or wallet. A real future workshop capture needs original content and actual browser input; the style test does not stand in for it.

The short silent concept reuses V11's exact six-solid scene/motion through a new wrapper, with redesigned nontechnical UV print and protected **Free to use. Creators paid.** / **Concept preview** labels. Existing physical time0–8s maps onto5.5s of output. Actual geometry/camera exports are checked against that mapping; old sources and movies remain unchanged. The footage previews material, weight, contact and camera direction, not a new signed transaction or implemented workshop resource.

Outputs, native PNGs, source/provenance records and decoded review sheets stay ignored under `.publication/sunset-launch-v12/`. Source-only reproduction uses the pinned cached dependencies/fonts/logo from the earlier rendering pipeline; no new package is installed. See `render-style.mjs` for pose/probe/full commands. Rendering needs those local licensed inputs and an isolated browser.

The public [concept evidence](../../evidence/launch-concept-v12.json) records the exact verified preview and sampled review limits. The35-second script remains proposed for review; a full film should follow the chosen script. No application feature, sample resource, onchain campaign, signature, deployment, social post or submission is part of this batch.

## Developer publishing only

The operator pushes verified local source commits from the repository root with:

```sh
git --git-dir=.sunset-git --work-tree=. push origin main
```

That command publishes source changes. People reading or using SUNSET resources do not run it. The generated video itself remains ignored.
